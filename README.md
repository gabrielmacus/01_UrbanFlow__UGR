# UrbanFlow

## Sprint 1
Análisis y depuración de los datos del sistema legacy paraobtener información relevante sobre las infracciones y de esta forma en el futuro poder incorporar los datos al nuevo sistema sin inconsistencias.

## Sprint 2
Procesamiento de evidencia visual mediante técnicas de visión artificial y OCR para validar las infracciones del sistema, vinculando automáticamente las capturas de radares con el registro de multas depurado.

### Objetivo

Aplicar los conocimientos adquiridos para el versionado decódigo, la organización, limpieza del código y la utilización de pandas.
